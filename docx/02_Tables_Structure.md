# 02 — Структура таблиць, баз даних та іменованих діапазонів

## 1. Головна таблиця бази даних: `AllData`

Таблиця `AllData` розміщена на аркуші **«Дані»** (в деяких версіях аркуш перейменовано на **«База»**). Це центральний журнал обліку всіх господарських операцій, транзакцій та рухів матеріальних цінностей у частині.

Тип об'єкта в Excel: `ListObject`.

## 2. Довідникові таблиці книги

### 2.1. Довідник субрахунків `tbAccaunts`
Розташований на аркуші **«Довідники»**. Використовується для інвентаризації та перевірки коректності проводок.
- **Колонка 1:** Номер субрахунку (наприклад `1014`, `1113`, `1513`, `1812`).
- **Колонка 2:** Найменування субрахунку (наприклад "Машини та обладнання", "Малоцінні необоротні матеріальні активи").
- **Колонка 3:** Тип активу / рахунку (наприклад, "Необоротні активи", "Запаси", "Оборотні активи").

### 2.2. Аркуш «Підрозділи»
Службовий аркуш без форматування таблиці. Використовується як тимчасовий буфер:
- Колонка **A (A1:A...)**: Список унікальних підрозділів, який заповнюється макросами перед показом форми `UserForm1`.

### 2.3. Аркуш «Список»
Службовий буферний аркуш для формування списків:
- Списки товарів конкретного підрозділу;
- Списки матеріально-відповідальних осіб (МВО);
- Використовується процедурами `ResiduseOnePeople.bas`, `MoveForUnit.bas` тощо.

### 2.4. Аркуш «Залишки 2» (`wsResiduse2`)
Розрахунковий аркуш, на якому зберігається оперативний стан залишків на поточний момент.
- **Named Range `Goods`:** Діапазон `wsResiduse2.Range("Goods")` — містить перелік доступної номенклатури на складі з їх реквізитами.
- Використовується всіма документними модулями для вибору товару при додаванні в накладні/акти.

## 4. Каталог іменованих діапазонів (Named Ranges)

Шаблони документів використовують іменовані клітинки та діапазони для заповнення реквізитів шапки, підвалу та керування нумерацією:

### 4.1. Накладна ф. 25 (`Invoice440_25.bas`)
- `invNum440_25` — поточний номер накладної (автоматично інкрементується макросом `SaveInv440_25`).
- `dateInv440_25` — дата накладної.
- `FromUnitInv440_25` — підрозділ / склад відправника.
- `fromMRPInv440_25` — матеріально-відповідальна особа відправника.
- `toUnitInv440_25` — підрозділ / склад одержувача.
- `toMRPInv440_25` — матеріально-відповідальна особа одержувача.
- `basis440_25` — підстава (наряд, рапорт тощо).
- `ServiceInv440_25` — служба забезпечення.
- `allCountInv440_25` — підсумкова кількість найменувань (прописом або числом).
- `allSumInv440_25` — підсумкова вартість за накладною.

### 4.2. Відомість ф. 57 (`payroll440_57.bas`)
- `invNum440_57` — номер відомості.
- `dateInv440_57` — дата відомості.
- `FromUnitInv440_57` — підрозділ-здавач.
- `toUnitInv440_57` — підрозділ-отримувач.
- `basis440_57` — підстава видачі.
- `allCountInv440_57`, `allSumInv440_57` — підсумки.
- `rngNames`, `rngNomenclatures`, `rngPrices`, `rngQuantityes` — горизонтальні діапазони заголовків колонок (до 19 товарів).

### 4.3. Акти списання (81 та 431)
- `invNumWOff81` / `invNumWOff` — лічильник номера акта списання.
- `dateWOff81` / `dateWOff` — дата складання акта.
- `FromUnitWOff81` / `FromUnitWOff` — підрозділ, в якому списується майно.
- `fromMRPWOff81` / `fromMRPWOff` — МВО підрозділу.
- `basisWOff81` / `basisWOff` — підстава списання.
- `allCountWOff81`, `allSumWOff81` — підсумкові суми та кількості списаного майна.

### 4.4. Інвентаризаційні описи (`Inventory.bas`, `InvertoryNonCurrentAssets.bas`)
- `invAsOf` — дата, станом на яку проводиться інвентаризація.
- `invUnit` — назва підрозділу, що інвентаризується.
- `invAccauntType` — тип рахунків ("Необоротні активи" або "Запаси").
- `invSubs` — перелік задіяних субрахунків у звіті (заповнюється автоматично).
- `ivnLastRowTable` — клітинка з підсумковим рядком "Разом за описом".
- `invLastRow` — останній рядок зони друку.
- `invTotalNumbers` — кількість порядкових номерів прописом.
- `invTotalQuantity` — загальна фактична кількість одиниць прописом.
- `invActualCost` — фактична сума прописом (грн/коп).
- `invTotalQuantityAccaunting` — кількість за даними бухобліку прописом.
- `invActualCostAccaunting` — вартість за даними бухобліку прописом.

### 4.5. Звіти залишків та руху
- `selectedUnit` — вибраний підрозділ для побудови індивідуального звіту.
- `AddOnePeriodFrom`, `AddOnePeriodTo` — початкова та кінцева дати періоду звіту Додаток 1 / ф. 18.
- `RngSumRes`, `RngTotalRes` — підсумкові діапазони зведеного розрахунку залишків.
- `Goods` — колонка унікальних найменувань товарів на аркуші `wsResiduse2`.
- `Z1` — технічна комірка ідентифікації типу документа у файлах, що імпортуються.
